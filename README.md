# El Médico Ancestral - versión 4

PWA estática para GitHub Pages, sin compilación.

## Incluye
- 330 recetas del recetario principal.
- 30 fichas botánicas con fotografías embebidas en `app.js`.
- 8 bonos interactivos con navegación interna, categorías y recetas.
- Consulta guiada, semáforo de seguridad, favoritos, Mi Botica, lista de compras y uso offline.

## Subir a GitHub Pages
1. Descomprimí el ZIP.
2. Copiá **el contenido** de `el-medico-ancestral-v4` en la raíz del repositorio o en la carpeta publicada.
3. En GitHub: Settings > Pages > Deploy from a branch.
4. Elegí la rama y la carpeta correspondiente.
5. Después de publicar, abrí una ventana de incógnito o borrá los datos del sitio para evitar la caché anterior.

Las imágenes de plantas están embebidas, por lo que no dependen de rutas externas.
